=========================================
 POS Sales Dashboard
=========================================

This module provides a modern and interactive **POS Sales Dashboard** 
inside the Odoo Point of Sale interface.

It enables real-time business insights, analytics, and performance tracking 
to help make better operational and sales decisions directly from POS.

The dashboard consolidates key metrics such as sales, products, customers, 
stores, and sessions into a single intuitive interface.

Features
========

* Real-time POS sales analytics
* Top selling products with quantity insights
* Top customers based on sales value
* Top POS product categories
* Store performance tracking
* Active POS sessions overview
* Payment methods summary
* Interactive charts (Bar & Pie)
* Store sales comparison (Month / Year)
* Session-based filtering
* Date filters (Today, Week, Month, Year)
* Notifications for new POS orders
* Product sales history view
* Dark and Light mode support
* Mobile-friendly dashboard view
* Top Cashiers analytics (orders & sales performance)

Usage
=====

1. Go to **Point of Sale**
2. Open the **POS Dashboard**
3. Use filters (Today, Week, Month, Year) to analyze data
4. Select a specific POS session if required
5. View insights such as:
   - Sales metrics
   - Top products and customers
   - Store performance
   - Cashier rankings
6. Click on records (products, categories) for detailed insights
7. Use charts for visual data analysis

Configuration
=============

* No additional configuration required
* Ensure **Point of Sale** module is installed
* Users must have access to POS data
* Optional: Configure POS sessions for filtered insights

Technical Notes
===============

* Built using OWL framework (Odoo Web Library)
* Uses Chart.js for interactive visualizations
* Data is fetched using optimized SQL queries
* Supports session-based and date-based filtering
* Lightweight and optimized for performance
* Designed for seamless integration with POS workflows
