POS Internal Stock Transfer

Transfer stock between warehouses directly from the Point of Sale interface with a single click.

Key Features

  • Create internal stock transfers directly from POS
  • Transfer stock from current POS warehouse to another warehouse
  • Controlled via POS configuration (Allow Send Stock option)
  • Automatically captures products and quantities from order lines
  • Creates stock transfer (stock.picking) instantly
  • Seamless integration with POS workflow

How It Works

Step 1 : Enable Feature in POS Configuration

Activate Allow Send Stock option in POS settings.

Step 2 : Click "Send Stock" in POS

Add products to cart and click the Send Stock button.

Step 3 : Select Destination Warehouse

A popup appears allowing you to choose the destination warehouse.

Step 4 : Stock Transfer Created

The system creates an internal transfer between warehouses based on selected products and quantities.

Step 5 : Validation & Warning Messages

The system ensures proper validation before creating the transfer:

  • ⚠️ Warning is shown if no products are selected before clicking Send Stock
  • ⚠️ Warning is shown if no destination warehouse is selected in the popup
