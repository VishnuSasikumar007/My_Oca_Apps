POS Salesperson

Enforce mandatory salesperson selection in the POS Payment Screen based on POS configuration.

Compatible with Odoo v19

Key Features

  • Select salesperson directly from the POS Payment Screen
  • Configure salesperson as mandatory from POS settings
  • Restrict order validation without selecting a salesperson
  • Automatically store salesperson in the POS Order
  • Supports multiple allowed salespersons per POS
  • Seamless integration with POS HR module

How It Works

Step 1 # Configure POS Settings

Navigate to Point of Sale → Configuration → Point of Sale, open your POS, enable the Salesperson Mandatory option, and select the allowed salespersons.

Step 2 # Select Salesperson in Payment Screen

Click the **Salesperson** button to open the salesperson selection popup.

The configured salespersons are listed in the selection popup.

The selected salesperson is stored in the POS Order in the backend.

Result # Validation Control

If no salesperson is selected when the mandatory option is enabled, the system will block order validation and prompt the user to select one.
