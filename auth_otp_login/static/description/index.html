Auth OTP Login (with Email)

Let users log in with a one-time code sent to their email, no password required.

  • Adds a passwordless "Log in with a code by email" option to the login page
  • Emails a secure, time-limited one-time code to the user
  • Live expiry countdown with automatic expired-code warning
  • Resend cooldown timer to prevent repeated code requests
  • Max attempts protection against brute-force code guessing
  • Show or hide the option from the login page anytime, from Settings
  • Fully compatible with the standard Odoo login workflow

Step 1

From the login page, click Log in with a code by email.

Step 2

Enter your email address and request a code.

Step 3

Enter the 6-digit code emailed to you to complete the login.

Live Expiry Countdown

A live countdown shows exactly how long the code stays valid. Once it hits zero, the code expires automatically and the Verify and log in button is disabled until a new code is requested.

Expired Code Warning

If the code isn't entered in time, a clear "expired" state is shown so the user immediately knows to request a new one instead of guessing why login failed.

Resend Cooldown

The Resend code button stays disabled with a live countdown until the configured cooldown passes, preventing repeated code requests and email spam.

Max Attempts Protection

After too many incorrect codes, the current code is invalidated and the user is asked to request a fresh one, protecting against brute-force guessing.

No User Found

If no user is found in the system, a warning message is displayed.

Settings

Configure everything from Settings > General Settings > Login with a code by Email:

  • Show or hide the "Log in with a code by email" link on the login page
  • Code Validity — how many minutes an emailed code stays valid
  • Max Attempts — how many wrong tries are allowed before the code is invalidated
  • Resend Cooldown — how many seconds before a new code can be requested

Turning the login link off hides it from the login page while keeping the OTP flow itself intact for anyone with the direct link.
