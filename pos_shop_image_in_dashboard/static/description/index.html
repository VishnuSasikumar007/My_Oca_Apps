POS Shop Image in Kanban

Display shop images directly in the Point of Sale dashboard for better visual identification.

Key Features

  • ✔ Add shop image to POS configuration
  • ✔ Display image in POS dashboard kanban view
  • ✔ Improves store identification visually
  • ✔ Clean integration with existing POS UI
  • ✔ Lightweight and easy to use

How It Works

Step 1 : Upload Shop Image

Go to POS configuration and upload your shop image.

Step 2 : Save Configuration

Save the POS configuration after uploading the image.

Step 3 : View in Dashboard

The uploaded image will be displayed in the POS dashboard kanban view.
